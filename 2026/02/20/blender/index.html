Blender basic function

移動視窗

middle mouse按下 -> 轉動視角
middle mouse前後 -> 視窗前進後退
shift + middle mouse -> 平移

others

  • 移動+shift -> 緩慢移動
  • 移動+ctrl -> 半格移動
  • alt+S/R/G -> 物件回到原縮放/旋轉/位置
  • T -> left function
  • N -> right function
  • 1/3/7 -> 正面/側面/俯視(+ Ctrl相反)

物件變形

G -> 移動物件
S -> 縮放物件
R -> 旋轉物件
G/S/R + X/Y/Z -> 軸線平移/縮放/旋轉物件(+數字 平移距離)
G + Shift + Z -> XY軸平面移動
Alt + G/S/R -> 回到初始設定
B(Box) -> 畫框同時選所有物件
C -> 選取多個物件(+ Wheel Up/Down縮小放大圓圈)

物件

shift + A -> mash -> 新增物件
左下 -> add uv square -> 決定面數(圓形) / 大小 / ring數 (決定後無法修改 除非新增新物件)
左側 -> move -> 移動物件
點選 + delete -> 刪除

選取多個物件

  • choose one + shift
  • B -> 圈選
  • C -> 移動選取

複製(+x, y, z延該軸移動)

  • shift + D
  • alt + D -> 同物件(捏形狀繪同時變更)
    z -> 切換模式

Cursor

  • shift + right -> 更改cursor place
  • 物件 + . -> 以該物件為中心
  • shift + S -> Cursor to selected -> Cursor至該物件中心
  • shift + S -> selected to Cursor -> 物件移動至Cursor
    right -> shed smooth -> 物件平滑

攝影機

  • 0 -> 攝影機角度
  • 物件 + . -> ctrl + alt + 0 -> 以物體為攝影中心
    H -> 物件消失
    A + H -> 隱藏所有物件
    alt + H -> 重新出現

object mode(left top)

  • ctrl + P -> parent
  • alt + P -> clear parent
    tab -> 切換 object / edit mode
    ctrl + tab -> different mode 選單
    F3 -> search func

edit mode

1, 2, 3 -> 點線面
E -> 延伸(可搭配R, S, G)
ctrl + R -> 新增loop
alt + 點線面 -> 選一整圈
shift + 點線面 -> choose multiple
ctrl + 點線面 -> 選取沿途路徑
點線面 + X -> 刪除所選
F -> 填補線面

modifiers

array

複製物件(可多個)
能更改物件間距(x, y, z) 疊加使用(同時x, y, z增加..等)
apply -> 確認
realtime -> 工作空間中可顯示物件(尚未apply不會顯示)
render -> 算圖不會顯示

plain axes

shift + A -> empty -> plain axes -> 可輔助使用
關閉relative offset
subject 右鍵 -> origin to 3D Cursor
接著可以以中心為圓心複製物件

bevel

更改物件島角
segments 增加面數

bollean

intersect

union重合

difference只留下有重疊部分

mirror

skin

外擴點, 面
