s216. 三仙鬥法 (Competition)

problem

思路

因為進行每次運算 數值之差不是沒有變化就是少2
所以可以從奇偶數開始想
先從小的開始推算:
1 1 2 -> 0 2 1(or 2 0 1) -> 1 1 0 -> 0 0 1(C win)
2 1 1 -> 1 0 2(or 1 2 0) -> 0 1 1 -> 1 0 0(A win)
可以看出 只有單一奇數或是單一偶數 該數為answer
也可以往大數推:
2k 1 2 -> 2k-1 2 1 -> … -> 2 1 2 -> ans = B
2k+1 1 2 -> 2k 2 1(回上面偶數) -> ans = C
